# Отдельная карточка товара

Маршрут: `/product/barelyef-new/`. Исходный макет: Figma `j1cOxgS2tGUfkq1AeQwrEH`, фрейм `1138:907`, 1920 × 6056. Существующая карточка `/product/barelyef` сохранена.

Компонент `EditorialProductPage` использует общие шрифты, палитру, маршрутизацию и `SiteHeader` / `SiteFooter` с отдельным вариантом `product`. CSS новой страницы ограничен префиксом `editorial-product`; общие компоненты сохраняют прежнее поведение по умолчанию.

Первый экран содержит фотографию, хлебные крошки, заголовок и панель покупки. Далее идут пять фотографий в асимметричной сетке, FAQ, новинки и футер. При ширине контента 1920px галерея начинается на y=933, FAQ на y=3394, новинки на y=4132, навигация футера на y=5310, логотип на y=5617. Общая высота 6056px. Геометрия адаптируется под десктоп, минимальная ширина проекта остаётся 1024px.

Фотографии экспортированы из отдельных слоёв Figma, включая итоговое кадрирование и наложенные заливки. Источники перечислены в `reference/product-editorial-assets.json`. Изображения трикотажного комплекта, название бомбера и подписи новинок сохранены в соответствии с макетом. В интерактивных рекомендациях используются полноценные исходники бомбера и шарфа с главной: затемнение и подпись поверх фото теперь появляются при hover, как в общем слайдере.

Правая панель закреплена CSS `position: sticky` на 60px от верха. Её родитель охватывает первый экран, галерею и FAQ, заканчиваясь за 56px до рекомендаций. Поэтому раскрытие FAQ автоматически меняет границу закрепления. На ширинах до 1600px галерея и FAQ оставляют место под панель шириной минимум 340px. Высота панели ограничена окном; при недостатке места внутренний скролл исключён из Lenis через `data-lenis-prevent`. `data-text-in-view` запускает появление всех её текстов после hero, включая внутреннюю прокручиваемую часть.

Подключены существующие `useHeroIntro`, `usePhotoReveal`, `useTextMotion`, `HoverText`, `ArrowHover`, `StringDivider`, `SectionCursor`, `FooterWordmark` и `ArrivalSlider`. Фото галереи и рекомендаций раскрываются общей центральной маской 1.8с / power4.inOut; параллакс удалён. Слайдер сохраняет hover, перетаскивание, инерцию, клавиатурные стрелки и автоскролл 18px/s. Курсор выведен через portal, чтобы контейнер с `container-type` не менял координаты его fixed-слоя. Hooks очищают анимации при размонтировании.

Страница использует общий SPA fade-переход из `docs/motion.md`. Локальный вход первого экрана следует товарной последовательности с нахлёстом: после releaseEntrance стартует фото, через 0.8с от PHOTO_REVEAL_START — заголовок, от START заголовка — шапка, крошки и панель. Фоновое фото сохраняет fade/scale, поскольку белая шапка расположена поверх него; `useHeroIntro` теперь отправляет START, а прежние потребители COMPLETE сохраняют своё ожидание. На заголовке стоит `data-text-in-view`, чтобы его низкая позиция в коротком окне не задерживала верхний интерфейс. Глобальный таймлайн переходов и правила прелоадера не менялись.

Подложка покупки — отдельный слой `.editorial-product__purchase-background` с исходными заливками. Она передана в `useHeroIntro` как необязательный backdrop и появляется вместе с промо-фото в одном tween: opacity 0→1 за 1.8с / power4.inOut. Текст сохраняет свой нахлёст. Внутренняя прокрутка перенесена в `.editorial-product__purchase-content`, поэтому фон остаётся неподвижным внутри sticky-панели. При reduced motion оба слоя сразу видны; общий cleanup снимает временные стили.

Выбор размера/цвета, вкладки без предоставленного содержимого и добавление в корзину остаются демо-контролами с `aria-disabled`, доступными для проверки hover и фокуса. Первый ответ FAQ открыт по макету и может сворачиваться; используется существующий `ProductQuestion` с необязательным `defaultExpanded`. Логотип и хлебная крошка ведут на главную, первая карточка новинок — на существующую карточку товара. Свободная карточка пуховика «Ох, и личность ты» в «Новинках» главной теперь ведёт на `/product/barelyef-new`; обычный anchor проходит через общую навигацию. Новая страница включена в генерацию статических HTML для прямого открытия после сборки.

Проверено в браузере при ширине контента 1920 и 1280px: закрепление при прокрутке, выход перед рекомендациями, сворачивание FAQ, появление фото и текста, hover текста/стрелок, перетаскивание слайдера без случайного перехода. При окне 1295×600 кнопка видна (нижняя граница 544px); при высоте 400px прокручивается сама панель. На 1920px галерея начинается на y=933, рекомендации на y=4132. Горизонтальной прокрутки и ошибок JS нет. Reduced motion дополнительно проверен по исходникам общих hooks. `npm run build` проходит; остаётся существующее предупреждение Vite о размере общего JS-бандла более 500 kB.

После возврата раскрытия проверен реальный клик по карточке пуховика с главной: exiting → entering → idle без прелоадера, заголовок/шапка/цена переходят в revealing, пока фото ещё revealing. Галерея проходит pending → revealing → complete, без translate и параллакс-обёрток; sticky сохраняет top=60px. Reduced motion проверен по коду общих hooks.
