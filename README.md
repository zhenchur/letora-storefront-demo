# Летора — демо магазина

React + TypeScript + Vite демо для согласования дизайна.

[Главная](https://zhenchur.github.io/letora-storefront-demo/) · [Новая карточка товара](https://zhenchur.github.io/letora-storefront-demo/product/barelyef-v3/)

Предыдущие карточки сохранены: [первая версия](https://zhenchur.github.io/letora-storefront-demo/product/barelyef/) · [вторая версия](https://zhenchur.github.io/letora-storefront-demo/product/barelyef-new/).

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:5174/

```sh
npm run build
```

## Публикация

Исходники находятся в `main`, опубликованная сборка — в `gh-pages`. В настройках Pages выбран источник Deploy from a branch, ветка `gh-pages`, корень `/`.

Локальная сборка использует корень `/`. Для GitHub Pages нужен `PAGES_BASE_PATH=/letora-storefront-demo/`; ссылки, маршруты и публичные ассеты учитывают этот префикс через `src/navigation/paths.ts`. Сборка для публикации в PowerShell:

```powershell
$env:PAGES_BASE_PATH = '/letora-storefront-demo/'
npm run build
Remove-Item Env:PAGES_BASE_PATH
```

Для обновления сайта нужно отправить содержимое `dist`, включая `.nojekyll`, в корень ветки `gh-pages`. Изменения исходников в `main` сами по себе сайт не обновляют.

Скрипт `scripts/write-pages.mjs` добавляет отдельные HTML для всех трёх товарных маршрутов: `/product/barelyef/`, `/product/barelyef-new/` и `/product/barelyef-v3/`. Прямой вход и обновление каждой карточки работают на статическом хостинге. Исходная демка заглушки находится в отдельном репозитории `zhenchur/letora`.

## Главная страница

Текущая главная — Figma `j1cOxgS2tGUfkq1AeQwrEH`, фрейм `1158:1460`, состояние меню `1162:1740`. Изменения описаны в `docs/home-refresh.md`.

Эталон — 1920 × 900. Экран занимает высоту окна, фото и расположение категорий адаптируются к его размерам. Макет рассчитан на десктоп от 1280 px и растягивается шире 1920 px. Минимальная ширина документа 1024 px; мобильная версия в этот этап не входит.

Сверстаны шапка, первый экран, блок о бренде с подписью «Люби», новинки, категории, выбор редакции и футер с формой подписки.

Первый экран содержит два промо-слайда, смену фотографий фейдом, центральный таймер и стрелки по обе стороны от него. Меню категорий расположено сверху: при наведении фото затемняется, управление промо скрывается и появляются пять названий моделей. Скобки активного пункта не сдвигают меню. Наведение на «Смотреть» приостанавливает таймер; после ухода отсчёт продолжается. Текущие параметры описаны в `docs/home-refresh.md` и `docs/motion.md`. Поиск, корзина, вход, переключатели подборок, категории и форма пока не выполняют действий; текстовые элементы позволяют посмотреть ховеры.

Карточки новинок и рекомендаций используют общий зацикленный drag-слайдер с инерцией и медленным автодвижением влево (18 px/s). В обычном состоянии под фотографией расположены название и ниже цена терракотовым цветом, без номера; при наведении фото затемняется, а строка с номером, названием и ценой следует за курсором по вертикали внутри карточки. Поведение и проверки описаны в `docs/arrivals.md`. Первые три карточки новинок на главной открывают соответственно первую, вторую и третью версии товара. Цены сохранены из макетов; у четвёртого фото цена отсутствует.

Строки секции «Категории» реагируют на наведение по всей ширине. Активное название становится курсивным indigo, без скобок и кнопки «Перейти». Две уменьшенные обложки синхронно раскрываются слева и справа на уровне центра выбранного названия. При смене категории и уходе прошлые обложки скрываются сразу. Ховеры текста используют общий посимвольный fade/blur без подъёма.

Анимация загрузки перенесена из демки заглушки. Она проигрывается при первоначальном открытии главной и обновлении любой страницы. Прямой вход на карточку, внутренние переходы и Back/Forward обходятся без прелоадера. Элементы страницы начинают появление после полного исчезновения прелоадера. Общий контракт описан в `docs/motion.md`.

На всех страницах подключена плавная прокрутка Lenis. Она запускается после прелоадера и использует общий GSAP ticker.

На главной и карточках товара подключены появления текста и фотографий при загрузке/прокрутке на основе `placeholder-react`. Фото с общим эффектом появления раскрываются прямоугольной маской из центра за 1.8 секунды; подписи новинок начинают появление вместе с раскрытием фото. Галерея третьей версии товара всегда видима и использует только параллакс. Общие модули учитывают reduced-motion, а переключение этой настройки сохраняет позицию страницы.

Переходы между главной и товаром выполняются без перезагрузки: текущие контент и фон плавно уходят, следующая страница появляется с фейдом фона и собственными появлениями элементов. Тайминги и последовательность основаны на заглушке; изменение фоновой заливки адаптировано по запросу пользователя. Back/Forward восстанавливает прокрутку без прелоадера. Прямой вход и обновление карточки проверены также в собранной версии.

Подпись «Люби» прорисовывается по штрихам с сохранением оригинального SVG, абзац под ней появляется общим построчным эффектом. На двух маленьких редакционных карточках используется тот же hover, что в новинках. Курсор с линией работает на промо и в блоке о бренде, но не в секции категорий; при переходе между смежными отмеченными областями линия сохраняется. Логотип футера появляется по символам с сохранением исходного SVG.

## Карточки товара

- `/product/barelyef/` — первая версия: фотографии складываются в стопку при прокрутке, шапка закреплена над галереей. В reduced-motion фотографии остаются обычной вертикальной галереей.
- `/product/barelyef-new/` — макет `1138:907`: асимметричная галерея, правая sticky-панель до рекомендаций, первый ответ FAQ открыт по макету. Фото используют общее раскрытие без параллакса. Подробнее: `docs/product-editorial.md`.
- `/product/barelyef-v3/` — текущий макет `1172:2209`: три крупных фотографии загружаются eager и всегда видимы, без анимации появления и `clipPath`. Статическая обрезка рамкой сохраняет параллакс от −15% до +15%; в reduced-motion фотографии неподвижны. Панель закреплена на 58 px от верха и останавливается у нижней границы FAQ; раскрытие ответа обновляет эту границу. В коротком окне содержимое панели прокручивается отдельно. Подробнее: `docs/product-v3.md`.

Все версии используют общие шрифты, анимации текста, hover стрелок, интерактивные разделители, FAQ и слайдер рекомендаций. В первой и третьей версиях FAQ закрыт по умолчанию; раскрывается «Сухая чистка» с существующим ответом. Первый экран появляется с нахлёстом фотографии, заголовка и интерфейса. Две новые версии используют общие `SiteHeader` / `SiteFooter` с вариантом `product` и курсор с линией на промо. Размер, цвет, вкладки без предоставленного содержимого и корзина остаются демо-контролами; покупки не имитируются.

Новые эффекты, у которых нет основы в заглушке, обсуждаются с пользователем.

## Материалы

- Фото и SVG сохранены напрямую из Figma; при запуске внешние ссылки на ассеты не нужны.
- Цветовые токены и TT Livret Subhead перенесены из существующего проекта `placeholder-react`.
- Wix Madefor Display взят из [официального репозитория Google Fonts](https://github.com/google/fonts/tree/main/ofl/wixmadefordisplay); лицензия рядом со шрифтом.
- Референс исходной первой секции: `docs/reference/hero-1920.png`.
- Карта исходных материалов остальных секций: `docs/reference/home-assets.json`; файлы лежат в `src/assets/home`.
- Обновлённые исходники главной: `src/assets/home-refresh`, описание — `docs/home-refresh.md`.
- Карты ресурсов новых карточек: `docs/reference/product-editorial-assets.json` и `docs/reference/product-v3-assets.json`; фотографии и SVG сохранены локально с точными исходниками и кадрированием.
- Под непрозрачной фотографией в Figma есть скрытый слой; исходник сохранён как `hero-underlay.png`, но не загружается страницей.
- Общие шапка и футер описаны в `docs/shared-shell.md`.

Компоненты остальных секций главной — `src/pages/home/HomeContent.tsx`, общий футер — `src/components/SiteFooter.tsx`.
