# Летора — демо магазина

React + TypeScript + Vite демо для согласования дизайна.

[Открыть демо](https://zhenchur.github.io/letora-storefront-demo/) · [Карточка товара](https://zhenchur.github.io/letora-storefront-demo/product/barelyef/)

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:5174/

```sh
npm run build
```

## Публикация

Исходники находятся в `main`, опубликованная сборка — в `gh-pages`. В настройках Pages выбран источник Deploy from a branch, ветка `gh-pages`, корень `/`.

Локальная сборка использует корень `/`. Для GitHub Pages нужен `PAGES_BASE_PATH=/letora-storefront-demo/`; ссылки, маршруты и публичные ассеты учитывают этот префикс через `src/navigation/paths.ts`. Сборка для публикации в PowerShell:

```powershell
$env:PAGES_BASE_PATH = '/letora-storefront-demo/'
npm run build
Remove-Item Env:PAGES_BASE_PATH
```

Для обновления сайта нужно отправить содержимое `dist`, включая `.nojekyll`, в корень ветки `gh-pages`. Изменения исходников в `main` сами по себе сайт не обновляют.

Скрипт `scripts/write-pages.mjs` добавляет отдельный HTML для `/product/barelyef/`, чтобы прямой вход и обновление карточки работали на статическом хостинге. Исходная демка заглушки находится в отдельном репозитории `zhenchur/letora`.

## Главная страница

Шапка и главный экран из Figma `j1cOxgS2tGUfkq1AeQwrEH`, фрейм `356:1311` внутри главной `356:1201`.

Эталон — 1920 × 900. Экран занимает высоту окна, фото и расположение категорий адаптируются к его размерам. Макет рассчитан на десктоп от 1280 px и растягивается шире 1920 px. Минимальная ширина документа 1024 px; мобильная версия в этот этап не входит.

Сверстаны шапка, первый экран, блок о бренде с подписью «Люби», новинки, категории, выбор редакции и футер с формой подписки.

Первый экран содержит два промо-слайда, смену фотографий фейдом, центральный таймер и стрелки. Фото появляются и переключаются через плавные scale/fade, заголовок и тег — построчным наборным эффектом. При наведении на кастомное меню появляются декоративные слова со смещением. Текущие параметры описаны в `docs/motion.md`. Ссылка на бомбер открывает карточку `/product/barelyef`. Поиск, корзина, вход, переключатели подборок, категории и форма пока не выполняют действий; текстовые элементы позволяют посмотреть ховеры.

Карточки новинок и рекомендаций используют общий зацикленный drag-слайдер с инерцией и медленным автодвижением влево (18 px/s). В обычном состоянии под фотографией расположены название и ниже цена терракотовым цветом, без номера, как в исходной вёрстке; при наведении фото затемняется, а строка с номером, названием и ценой следует за курсором по вертикали внутри карточки. Поведение и проверки описаны в `docs/arrivals.md`. Для текстов остальных карточек и категорий подключены ховеры из заглушки. При наведении на категорию появляется обложка с номером, активное название становится белым и заключается в скобки; геометрия списка сохраняется. Цены сохранены из соответствующих макетов; у четвёртого фото новинок цена пока отсутствует. Очевидная опечатка «возвтарт» исправлена на «возврат».

Анимация загрузки перенесена из демки заглушки. Она проигрывается при первоначальном открытии главной и обновлении любой страницы. Прямой вход на карточку, внутренние переходы и Back/Forward обходятся без прелоадера. Элементы страницы начинают появление после полного исчезновения прелоадера. Общий контракт описан в `docs/motion.md`.

На обеих страницах подключена плавная прокрутка Lenis. Она запускается после прелоадера и использует общий GSAP ticker.

На главной и карточке товара подключены появления текста и фотографий при загрузке/прокрутке на основе `placeholder-react`. Обычные фото раскрываются прямоугольной маской из центра за 1.8 секунды, связанные подписи появляются следом. Общие модули учитывают reduced-motion, а переключение этой настройки сохраняет позицию страницы.

Переходы между главной и товаром выполняются без перезагрузки: текущие контент и фон плавно уходят, следующая страница появляется с фейдом фона и собственными появлениями элементов. Тайминги и последовательность основаны на заглушке; изменение фоновой заливки адаптировано по запросу пользователя. Back/Forward восстанавливает прокрутку без прелоадера. Прямой вход и обновление карточки проверены также в собранной версии.

Фотографии товара при прокрутке складываются в стопку: уходящий снимок уменьшается и исчезает под следующим. Маской раскрывается только первое фото галереи; остальные показываются при прокрутке без дополнительного раскрытия. В reduced-motion они остаются обычной вертикальной галереей. Шапка товара закреплена над галереей.

FAQ закрыт по умолчанию; плавно раскрывается только «Сухая чистка» с существующим ответом. Стрелки используют общий эффект замены при наведении, разделители реагируют на пересечение курсором. Подпись «Люби» прорисовывается по штрихам с сохранением оригинального SVG, абзац под ней появляется общим построчным эффектом. Контракты описаны в `docs/motion.md`. Первый экран товара появляется с нахлёстом: во время раскрытия фото подключаются заголовок, шапка и остальные элементы. На двух маленьких редакционных карточках используется тот же hover, что в новинках. В секциях бренда и категорий работает курсор с линией без слов; логотип футера появляется по символам с сохранением исходного SVG. Остальные действия магазина остаются следующими этапами.

Новые эффекты, у которых нет основы в заглушке, обсуждаются с пользователем.

## Материалы

- Фото и SVG сохранены напрямую из Figma; при запуске внешние ссылки на ассеты не нужны.
- Цветовые токены и TT Livret Subhead перенесены из существующего проекта `placeholder-react`.
- Wix Madefor Display взят из [официального репозитория Google Fonts](https://github.com/google/fonts/tree/main/ofl/wixmadefordisplay); лицензия рядом со шрифтом.
- Референс первой секции: `docs/reference/hero-1920.png`.
- Карта исходных материалов остальных секций: `docs/reference/home-assets.json`; файлы лежат в `src/assets/home`.
- Под непрозрачной фотографией в Figma есть скрытый слой; исходник сохранён как `hero-underlay.png`, но не загружается страницей.
- Общий каркас для соседней задачи карточки товара описан в `docs/shared-shell.md`.

Компоненты остальных секций главной — `src/pages/home/HomeContent.tsx`, общий футер — `src/components/SiteFooter.tsx`.
